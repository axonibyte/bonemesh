# BoneMesh Multiprotocol Interop Suite

This folder will hold the language-agnostic test harnesses (testing-methodology
tiers 5-9) that drive every BoneMesh implementation as a black box over TCP:
fake-peer fault injection, containerized mixed-language meshes, seeded fuzzing,
concurrency/convergence checks, and simulated meshes with nemesis operations.

It is also the repository's root reaper tenant.
